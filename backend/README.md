# Backend

Server-side API for both the Expo app and desktop web app.

```text
src/
  api/       HTTP routes and request/response schemas
  core/      configuration, security, and shared infrastructure
  db/        database connection, migrations, and repositories
  models/    domain and persistence models
  services/  business, prediction, and integration logic
tests/       automated backend tests
```

The backend framework and database will be selected when the product flows and data requirements are defined.
